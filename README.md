### 📐 Systems Philosophy

> **Local-First & Resilient** — Critical healthcare and research systems must remain fully functional offline. Network is an enhancement, not a prerequisite.
> 
> **Zero-Knowledge by Design** — Cryptographic isolation, hardware-backed keys, and zero-telemetry architectures protect sensitive patient and user data at rest and in transit.
> 
> **High-Fidelity Engineering** — Sub-millisecond rendering loops, predictable memory footprints, and defensive typing over quick abstractions.
